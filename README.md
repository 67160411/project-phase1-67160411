# คำถามทบทวนความเข้าใจ (ตอบใน README.md ข้อละ 2- 3 ประโยค)

## 1. resource ของคุณ เลือกฟิลด์ใดเป็นค่าที่ต้องซ้ำ เพราะเหตุใด และทำไม route POST จึงต้องตอบ 409 แทนที่จะเป็น 400 เมื่อฟิลด์นั้นซ้ำกับข้อมูลเดิม

เลือก `title` เป็นค่าที่ไม่ซ้ำ เพราะใช้แยกแยะงานแต่ละรายการ เมื่อ `title` ซ้ำกับข้อมูลเดิม จึงตอบ `409 Conflict` เพราะข้อมูลถูกต้องแต่ขัดแย้งกับข้อมูลที่มีอยู่ ไม่ใช่ `400 Bad Request` ที่ใช้เมื่อส่งข้อมูลไม่ถูกต้องหรือไม่ครบ

## 2. ถ้าจะเพิ่ม endpoint สำหรับแก้ไขข้อมูลบางฟิลด์(ไมใช่ทั้งระเบียน) โดยไม่กระทบ PUT ที่มีอยู่ ควรใช้ Method ใดและ route เดิมต้องแก้อย่างไร

ใช้ PATCH `/api/v1/tasks/:id` สำหรับแก้ไขเฉพาะบางฟิลด์ โดย ไม่ต้องแก้ Route ของ PUT ซึ่ง PUT ยังคงใช้แก้ไขข้อมูลทั้งระเบียนเหมือนเดิม
