| Method | URI                  | คำอธิบาย                  | Status Code ที่ต้องจัดการ |
| ------ | -------------------- | ------------------------- | ------------------------- |
| GET    | `/api/v1/tasks`      | ดึงรายการงานทั้งหมด       | 200                       |
| GET    | `/api/v1/tasks/{id}` | ดึงข้อมูลงานตาม ID        | 200, 404                  |
| POST   | `/api/v1/tasks`      | เพิ่มข้อมูลงานใหม่        | 201, 400, 409             |
| PUT    | `/api/v1/tasks/{id}` | แก้ไขข้อมูลงานทั้งระเบียน | 200, 400, 404             |
| DELETE | `/api/v1/tasks/{id}` | ลบข้อมูลงาน               | 200, 404                  |
